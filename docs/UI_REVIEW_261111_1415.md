# รีวิว UI/UX — lineup-nextjs (11 พ.ย. 2569)

ผู้รีวิว: Symboli Rudolf (Claude) · skill `ui-ux-pro-max` · #project/lineup-nextjs #agent/rudolf
ขอบเขต: ไล่อ่านโค้ด UI ทั้งหมด (`src/app/**/*.tsx` ~8,700 บรรทัด) + เช็คอินนักเรียน + dashboard ครู ละเอียด

> ⚠️ **รีวิวจากโค้ดเท่านั้น ยังไม่ได้เปิดแอปจริง** — `node_modules` หายไป รัน dev server ไม่ได้
> ไม่มี screenshot · ตัวเลข contrast เป็นค่าประมาณจากสี Tailwind บนพื้น `slate-950` (ยังไม่ได้วัดบนจอจริง)

## ภาพรวม

แอปใช้ธีมมืด glassmorphism โทน cyan/indigo ฟอนต์ Sarabun + Outfit · โครงหลักดีอยู่แล้ว:

- ✅ ปุ่มหลักของหน้าเช็คอินใหญ่ เต็มความกว้าง (`py-5`) กดง่ายบนมือถือ
- ✅ รองรับ safe-area (iPhone notch / home bar) — `safe-px` `safe-pb` `safe-pt`
- ✅ dashboard แยก **ตาราง (จอใหญ่)** กับ **การ์ด (มือถือ)** ชัดเจน
- ✅ มี focus ring 209 จุด, popup มี `role="dialog"` + `aria-modal`
- ✅ ฟอนต์ Sarabun รองรับไทยดี — skill แนะนำ Inter+Nunito แต่ **ไม่มีอักษรไทย ไม่ควรเปลี่ยน**

## แผนแก้ที่แนะนำ

1. **รอบเดียวจบ P1 (ข้อ 1–3)** — แก้เชิงกลไก ส่วนใหญ่เป็นการเปลี่ยน class · ตั้ง token สีข้อความใน `globals.css`
   (`--text-muted` = slate-400 ฯลฯ) แล้วแทนที่ทั้งแอป → ส่งให้ **Tokai Teio** หรือ **Tomi** ทำ + build

4. ก่อนแก้: `npm install` + `npm run build` ให้ผ่านก่อน (node_modules หาย) · หลังแก้ถ่าย screenshot ก่อน/หลังเทียบ
